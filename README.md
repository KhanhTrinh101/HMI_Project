# HMI project

This project focuses on the HMI monitor in vehicle
 
## Feature
- About **Media player**:\
. We can play list songs with next, run, previour.\
. Repeat current song.\
. Shuffle in list songs.\
. Displayed with multiple language.

- About **Map**:\
. Navigate location.\
. Can displayed in small screen.

- About **Air Conditioner**:\
. Setting air direction with 3 mode.\
. Setting air level from 1 to 10.\
. Setting fan speed with 3 mode.
